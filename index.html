Open-source tool

AWS Security Auditor

Scans an AWS account for security misconfigurations in minutes, work that would otherwise take hours of manual review.

  • Checks IAM and S3 configuration against five CIS AWS Foundations Benchmark controls through the AWS API (boto3).
  • Runs read-only under the AWS-managed SecurityAudit policy and writes a timestamped pass/fail report.
  • Free and ready to use for small teams and non-profits that can't afford commercial cloud-security tools.

  • Amazon S3

Graduation project

TrapPot

An AI-powered honeypot that lures in real attackers, then detects and classifies their attacks in real time.

  • Built a Cowrie SSH/Telnet honeypot that captures genuine live attack traffic instead of relying on simulated data.
  • Trained a Random Forest model, as part of the project team, to classify attacks automatically from Zeek network logs.
  • Streamed results through an ELK Stack pipeline for real-time monitoring in Kibana, all orchestrated with Docker.
